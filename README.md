# Henry Golatt — Portfolio

A personal portfolio website for **Henry Golatt**, built with React. Features multiple pages, a chatbot assistant, smooth scrolling, and SEO-ready configuration.

🌐 **Live Site:** [https://yourdomain.com](https://yourdomain.com)

---

## ✨ Features

- 🎨 Multi-page React app (Home, About, Services, Testimonials, Gallery, Contact)
- 💬 Built-in chatbot for visitor engagement
- 🖱️ Smooth scrolling and scroll-to-top on route change
- 📱 Fully responsive design
- 🔍 SEO optimized (`sitemap.xml`, `robots.txt`)
- ⚡ Fast, modern React setup

---

## 🛠️ Tech Stack

- **React** (with React Router v6)
- **JavaScript (ES6+)**
- **CSS** (custom styling)
- **React Hooks** (custom `useSmoothScroll`)

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn

### Install dependencies

```bash
npm install
```
